# Family Cookbook

A small web page for picking meals for the week and building a grocery list with estimated costs.

- The data lives in a Google Sheet (tabs: Meals, Ingredients, Prices) shared as "anyone with the link can view". The Sheet ID is set at the top of the script in `index.html`.
- A meal fills as many days on the planner as it usually lasts.
- The grocery list adds up the share of each package the planned meals use and rounds up to whole packages.
- Plans and ticked-off items are saved in the browser on each device.

Hosted with GitHub Pages. On a phone, open the page and use "Add to Home Screen" to use it like an app.
